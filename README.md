The funniest one-line apology from an office printer, 120 characters max: after four years of cheap paper, staples in its throat and 6am colour requests, it quits — and takes the toner with it.

## Run it

```sh
node main.ts
```

This writes the single apology line to `/output/entry.txt` (one line, no trailing newline, byte-identical on every run).
